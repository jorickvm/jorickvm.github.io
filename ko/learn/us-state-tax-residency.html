미국 주별 세법상 거주

주를 찾아 주 소득세 거주자가 될 수 있는 기준 일수, 판정 근거(항구적 주거지와 일수, 반증 가능한 추정, 숙박 일수 중 무엇인지), 계산 방법, 주 공식 출처를 확인하십시오. 현재 21개 주를 다루고 있습니다.

검색 결과에 해당하는 주가 없습니다.

주기준 일수판정 근거열기
네브래스카주 183일 이상 주거지 + 일수 →
노스다코타주 210일 초과 주거지 + 일수 →
뉴욕주 183일 초과 주거지 + 일수 →
뉴저지주 183일 초과 주거지 + 일수 →
로드아일랜드주 183일 초과 주거지 + 일수 →
매사추세츠주 183일 초과 주거지 + 일수 →
메릴랜드주 183일 이상 주거지 + 일수 →
메인주 183일 초과 주거지 + 일수 →
미네소타주 183일 이상 주거지 + 일수 →
버몬트주 183일 초과 주거지 + 일수 →
버지니아주 183일 초과 주거지 + 일수 →
아이다호주 270일 초과 주거지 + 일수 →
애리조나주 270일 초과 추정 →
오리건주 200일 초과 주거지 + 일수 →
오하이오주 212박 초과 숙박 일수 →
조지아 183일 이상 롤링 12개월 →
캘리포니아주 270일 초과 추정 →
코네티컷주 183일 초과 주거지 + 일수 →
콜로라도주 183일 초과 주거지 + 일수 →
펜실베이니아주 183일 초과 주거지 + 일수 →
하와이주 200일 초과 추정 →

> 183은 183일을 초과한다는 뜻이므로 184일째에 기준선을 넘습니다. ≥ 183은 183일 이상이라는 뜻이므로 183일째에 이미 해당합니다. '주거지 + 일수'는 주 안의 주거지와 일수를 함께 요구하고, '추정'은 일수만으로 생기는 반증 가능한 추정이며, '숙박 일수'는 일수가 아니라 밤을 셉니다.

일수는 주 거주 판정 기준 중 하나입니다. 대부분의 주는 생활 근거지(실제 본거지가 어디인지)를 이유로도 거주자에게 과세하며, 법정 판정 기준은 대개 일수와 함께 항구적 주거지를 요구합니다. 각 문서에 주의 공식 출처를 링크해 두었습니다. 이 페이지는 세무 자문이 아닙니다.
