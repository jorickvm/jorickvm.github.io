국가로 집계할 대상 선택

국가 수 집계는 방문 합계를 어떤 목록을 기준으로 셀지 정합니다. 유엔 국가나 모든 장소 같은 목록을 고를 수 있으며, 설정 → 여행 추적 → 국가 수 집계에서 바꿉니다.

바뀌는 것

이 목록은 요약의 국가 카드에 표시되는 합계(목록 전체 수 중 몇 개인지), 국가와 대륙 시트, 공유 카드, 위젯의 기준이 됩니다. 목록에 영토가 포함되면 카드 이름이 국가 대신 장소로 표시됩니다. 여행이나 트래커는 바뀌지 않으며, 지도에는 방문한 모든 장소가 계속 강조됩니다.

목록 고르기

  1. 설정 → 여행 추적 → 국가 수 집계를 여십시오.
  2. 집계 방식을 탭하십시오. 값에는 195개국, 모든 장소, 직접 만든 목록의 장소 수처럼 현재 목록이 표시됩니다.
  3. 유엔 회원국에 옵서버 국가인 바티칸 시국과 팔레스타인을 더하려면 유엔 국가 추가를 고르십시오. 해외 영토와 속령까지 포함하려면 모든 장소 추가를 고르십시오. 해당 목록이 이미 선택되어 있으면 그 프리셋 행은 유엔 국가 제거로 표시됩니다. 또는 국가 검색…으로 찾아 장소를 하나씩 체크할 수도 있습니다.
  4. 완료를 탭하십시오. 선택 화면이 닫히면 변경 내용이 저장됩니다.

요약의 국가 시트 맨 위에 있는 / N을 탭해도 같은 선택 화면이 열립니다. 목록은 비워 둘 수 없으며, 장소를 하나 이상 선택할 때까지 완료를 사용할 수 없습니다.

직접 만든 목록은 세계 전체에 대한 비율이 아니므로, 국가 시트는 이 경우 '세계 대비' 표현을 표시하지 않습니다.

여러 대륙에 걸친 국가

집계 방식 아래의 여러 대륙에 걸친 국가 섹션에는 이집트처럼 두 대륙에 걸쳐 있는 몇몇 국가가 나열됩니다. 국가마다 대륙 하나를 고르거나 둘 다를 고르십시오. 둘 다를 고르면 그 국가는 대륙 합계를 포함해 두 대륙 각각에 집계됩니다.

유엔 회원국 표시

설정 → 화면 모드 → UN 구분 표시를 켜면 국가 선택 화면과, 모든 장소를 표시할 때의 요약 장소 목록에서 유엔 회원국과 옵서버 국가가 표시됩니다.

합계가 지도와 다르게 보이는 경우

지도에는 방문한 모든 장소가 강조되지만, 합계에는 목록에 있는 장소만 포함됩니다. 대개 영토 때문에 차이가 납니다. 영토까지 집계하려면 모든 장소 추가를 고르십시오.

이어서 읽기

  • 언어 및 국가명 인터페이스, 국가명, 내보내기 언어를 설정합니다.
  • 요약과 지도 이해하기 여행이 합계로 어떻게 나타나는지 봅니다.
  • 시작하기 처음으로 돌아가 전체 설정 과정을 살펴봅니다.

해결되지 않은 경우

AtlasDays 지원팀에 문의할 때 해당 날짜, 예상한 결과, 실제로 일어난 상황을 함께 알려 주십시오.
