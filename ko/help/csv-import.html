CSV 가져오기

헤더 행이 있는 CSV를 준비해 설정 → 가져오기 → CSV 파일에서 선택하고, 여행을 저장하기 전에 확인 화면에 나온 문제를 해결하십시오.

파일 가져오기

  1. 설정 → 가져오기 → CSV 파일을 여십시오.
  2. CSV 예시나 형식 참조를 참고해 파일을 준비하십시오.
  3. 파일 앱에서 CSV를 선택하십시오.
  4. 유효한 행, 오류가 있는 행, 중복, 겹침 경고를 확인하십시오.
  5. 받아들일 행만 가져오십시오.

원본 파일에서 오류 수정

국가, 주, 날짜, 필수 헤더를 판별하지 못하면 확인 화면에 행 번호와 이유가 표시됩니다. CSV에서 해당 행을 고친 다음 파일을 다시 가져오십시오.

경고는 확인하라는 신호

중복은 이미 타임라인에 있는 여행을 한 번 더 넣는 경우일 수 있습니다. 겹침은 실제로 맞을 수도 있고, 같은 체류를 두 가지 형태로 기록한 것일 수도 있습니다. 모든 행을 그대로 받아들이지 말고 날짜와 장소를 확인하십시오.

저장하기 전에는 타임라인이 그대로

파일을 선택하고 확인 화면을 보는 것만으로는 여행이 추가되지 않습니다. AtlasDays는 마지막 가져오기 동작을 거친 뒤에야 받아들인 행을 저장합니다.

모든 행이 오류로 표시되는 경우

첫 행에 Country(국가) 헤더가 있는지 확인하고 날짜 형식이 정확한지 살펴보십시오. 지원하는 열과 예시는 CSV 형식 참조에서 볼 수 있습니다.

이어서 읽기

  • CSV 형식 참조 지원하는 열, 날짜, 예시를 확인합니다.
  • 여행 날짜가 처리되는 방식 가져온 기록이 날짜를 어떻게 유지하는지 설명합니다.
  • 내보내기 및 보고서 기록을 스프레드시트나 PDF로 내보냅니다.

해결되지 않은 경우

AtlasDays 지원팀에 문의할 때 해당 날짜, 예상한 결과, 실제로 일어난 상황을 함께 알려 주십시오.
