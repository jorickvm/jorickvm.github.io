CSV 형식 참조

필수 열은 Country(국가) 하나뿐입니다. AtlasDays는 지원하는 열을 헤더 이름으로 찾기 때문에 열 순서는 상관없습니다.

권장 헤더

Country,State,Start Date,End Date,Purpose,Notes

  • Country: 영어 국가 이름, ISO 두 글자 코드, 또는 널리 쓰이는 별칭입니다.
  • State: 미국 주 이름, 우편 약자, 또는 US-CA 같은 ISO 하위 구역 코드이며, 선택 항목입니다.
  • Start Date / End Date: 아래 규칙에 따라 정확한 날짜, 연도, 또는 빈 칸입니다.
  • Purpose: Tourism(관광), Business(업무), Medical(의료), Transit(환승), Personal(개인) 중에서 씁니다. Transit이 아닌 목적은 쉼표로 구분해 여러 개를 넣을 수 있습니다.
  • Notes: 자유롭게 쓰는 텍스트이며, 선택 항목입니다.

날짜 형식

정확한 날짜

두 날짜 열 모두에 yyyy-mm-dd 형식을 사용하십시오. End Date를 비워 두는 것은 체류가 이어지고 있는 여행일 때뿐입니다.

연도

Start Date에 네 자리 연도를 쓰십시오. End Date에는 연도를 쓰거나, 같은 해를 뜻하도록 비워 둘 수 있습니다. 여러 해에 걸친 구간은 해마다 하나씩 연도만 기록으로 나뉩니다.

날짜를 전혀 쓰지 않는 경우

날짜 칸을 둘 다 비워 두십시오. 해당 국가는 날짜 없는 방문으로 남습니다. 방문한 장소에는 포함되지만 일수 합계에는 전혀 반영되지 않으며, 리포트에는 날짜 미상으로 표시됩니다. 이런 형태의 기록은 CSV 가져오기로만 만들 수 있습니다.

미국 주 행

State는 미국 여행에만 사용하십시오. 한 번의 미국 방문에서 여러 주를 다녔고 주 단위 기록이 필요하다면 주마다 한 행씩 쓰십시오. 국가 단위로만 관리한다면 주를 비운 미국 행으로도 충분합니다.

Transit(환승)

국가에 입국하지 않았다면 Purpose에 Transit(환승)이라고 쓰십시오. Transit은 배타적입니다. Tourism(관광)이나 Business(업무)를 비롯한 다른 목적과 함께 쓰지 마십시오.

기재 예시

Country,State,Start Date,End Date,Purpose,Notes
France,,2026-03-01,2026-03-05,Tourism,
United States,CA,2026-04-10,2026-04-15,Business,Conference
Japan,,2024,,Tourism,Dates not known
United Arab Emirates,,2026-05-01,2026-05-01,Transit,Airport connection

구분자와 따옴표

AtlasDays는 헤더 행을 보고 쉼표, 세미콜론, 탭으로 구분된 파일을 가려냅니다. 구분자나 줄바꿈이 들어 있는 필드는 일반적인 CSV 규칙대로 따옴표로 감싸십시오.

값을 인식하지 못하는 경우

ISO 국가 코드, 오해의 여지가 없는 영어 국가 이름, ISO 형식 날짜, 표준 미국 주 이름이나 코드를 사용하십시오. 원본 행 번호를 남겨 두면 가져오기 확인 화면과 비교하기 쉽습니다.

이어서 읽기

  • 내보내기 및 보고서 기록을 스프레드시트나 PDF로 내보냅니다.
  • CSV 가져오기 이 형식을 읽어 들이는 가져오기 흐름입니다.
  • Flighty 가져오기 대신 Flighty에서 항공편 기록을 가져옵니다.

해결되지 않은 경우

AtlasDays 지원팀에 문의할 때 해당 날짜, 예상한 결과, 실제로 일어난 상황을 함께 알려 주십시오.
