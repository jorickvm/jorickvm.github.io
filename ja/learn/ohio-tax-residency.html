オハイオ州の212接触期間ルール：居住者と推定されるのはいつか

オハイオ州の数え方は多くの州とは異なります。数えるのは「接触期間」で、これは実質的に宿泊のことです。暦年で212を超えると、オハイオ州の居住者と推定されます。

最終確認：2026年8月

要点：オハイオ州は滞在を暦日ではなく接触期間で測ります。接触期間とは実質的に宿泊のことで、オハイオ州外の住まいを離れて夜を過ごし、かつ連続する2日のそれぞれについて州内で一部の時間を過ごした場合に成立します。暦年で212を超える接触期間（213以上）があると、オハイオ州の居住者と推定されます。非居住者と推定されるには、接触期間が212以下であること、通年でオハイオ州外に住まいがあること、そしてOhio Nonresident Statement（非居住者であることの申告書、様式IT 10）を提出していることが必要です。

ルールの内容

日数で居住を判定する州の多くは、州内で1日の一部でも過ごせばまる1日として扱います。オハイオ州は違います。Ohio Rev. Code §5747.24では、滞在は接触期間で測られ、判定は明確な居住者の線引きではなく推定として組み立てられています。

  • 接触期間が212以下の場合。あわせて通年でオハイオ州外に少なくとも1か所の住まいを維持し、所定の宣誓書を提出していれば、オハイオ州にドミサイル（住所地）がないものと推定されます。
  • 接触期間が212を超える場合。接触期間が213以上に達すると（または州外に住まいがないと）、通年でオハイオ州にドミサイルがあるものと推定され、居住者として課税されます。

推定であるため、証拠によって反対の結論を主張することはできますが、212の線を越えると立証の負担が移ります。AtlasDaysが管理するのはこの基準です。接触期間を212以下に保てば、判定のうち日数に関する部分は満たされます。

数え方

接触期間は暦日ではありません。オハイオ州外の住まいを離れて夜を過ごし、連続する2日のそれぞれについて、どれほどわずかであってもオハイオ州内で時間を過ごした場合に、接触期間が1つ成立します。オハイオ州で寝る必要はありません。月曜と火曜の一部をオハイオ州で過ごし、夜はケンタッキー州のホテルに泊まった場合も、住まいを離れて夜を過ごしているため接触期間1つになります。数えないのは、夜に自分の住まいへ戻る形の訪問です。

  1. オハイオ州外の住まいを離れて夜を過ごした宿泊を、すべて洗い出します。
  2. その宿泊ごとに、前日と翌日の両方についてオハイオ州内で一部の時間を過ごしたかを確認します。
  3. 該当すれば接触期間1つとして数えます。接触期間は連続している必要はありません。
  4. 暦年全体で合計します。213以上になると、その年はオハイオ州の居住者と推定されます。

例。ケンタッキー州に住み、仕事で頻繁にオハイオ州へ通っている場合。多くは日帰りで車で入り、同じ日の夜に帰宅します。夜に住まいを離れていないため、こうした日中の訪問は接触期間になりません。

一方、コロンバスのホテルに宿泊し、到着日と出発日の両方にオハイオ州にいた旅行もあります。これらはそれぞれ接触期間1つです。オハイオ州で働いた2日の間にケンタッキー州側のホテルで過ごした夜も数えます。夜をオハイオ州で過ごす必要はなく、住まいを離れていれば足りるからです。こうした宿泊が年間で213以上になると、自宅からの日帰りが一度も数えられていなくても、オハイオ州は州内にドミサイルがあったものと推定します。

日数だけで決まるわけではありません

接触期間は機械的な部分にすぎません。オハイオ州で問われているのはドミサイル、つまり真の固定した住まいがどこにあるかです。接触期間による推定はその広い判定の近道であり、オハイオ州最高裁判所は、明確な日数基準を満たしても、より広い事実関係が反対を示す場合には、それだけでドミサイルが決まるわけではないと判断しています。実務上の要点は2つです。通年でオハイオ州外に住まいを維持することが非居住者の推定の一部であること、そしてOhio Nonresident Statement（様式IT 10、またはIT 1040のチェックボックス）を期限である翌年10月15日までに提出しなければならないことです。提出を怠ると、接触期間の数にかかわらず、オハイオ州は通年で州内にドミサイルがあったものと推定できます。

AtlasDaysでオハイオ州の接触期間ルールを管理できます

旅行を一度記録するだけで、AtlasDaysが記録済みのオハイオ州旅行に含まれる宿泊数を暦年ごとにiPhone内で計算し、212を超える前に通知します。ただし、オハイオ州に2日連続で滞在しながら宿泊自体は州外だった場合に法的に生じる接触期間は自動で加算できません。そのような宿泊は別途確認してください。

よくある質問

居住者と推定されずにオハイオ州で持てる接触期間はいくつまでですか？

暦年で212までです。接触期間が213以上になると、オハイオ州の居住者と推定されます。非居住者と推定され続けるには、通年でオハイオ州外に住まいがあること、およびOhio Nonresident Statement（様式IT 10）を提出していることも必要です。

接触期間とは何ですか。1日とはどう違いますか？

接触期間とは、実質的に住まいを離れた宿泊のことです。オハイオ州外の住まいを離れて夜を過ごし、連続する2日のそれぞれについて州内で一部の時間を過ごすことを指します。夜そのものをオハイオ州で過ごす必要はありません。自分の住まいで寝る日帰りは接触期間になりません。この点が、1日の一部でも数える方式とは異なります。

オハイオ州の非居住者として扱われるには何か提出が必要ですか？

必要です。接触期間が212以下で、オハイオ州外に住まいがある場合でも、非居住者の推定はOhio Nonresident Statement（様式IT 10、またはIT 1040のチェックボックス）を期限内に提出することが前提です。提出を怠ると、オハイオ州は通年で州内にドミサイルがあったものと推定できます。

Ohio Rev. Code §5747.24。接触期間による判定については、Ohio Department of Taxation（オハイオ州税務局）のFAQ所得税：オハイオ州の居住と居住者控除で解説されています。
