CSV Import

Prepare a header-based CSV, choose it under Settings → Import → CSV, and resolve the preview before saving any trips.

Import the file

  1. Open Settings → Import → CSV.
  2. Use the example or format reference to prepare the file.
  3. Select the CSV from Files.
  4. Review valid rows, invalid rows, duplicates, and overlap warnings.
  5. Import the rows you accept.

Fix errors in the source file

The preview reports a row number and reason when it cannot resolve a country, state, date, or required header. Correct that row in the CSV and import the file again.

Warnings are review prompts

A duplicate can repeat a trip already in Timeline. An overlap can be legitimate or can represent two versions of the same stay. Check the dates and places rather than accepting every row automatically.

Only saving changes your Timeline

Selecting a file and viewing the preview does not add trips. AtlasDays writes the accepted rows only after the final import action.

If every row is invalid

Confirm the first row contains a Country header and check the exact date formats. See the CSV Format Reference for supported columns and examples.
