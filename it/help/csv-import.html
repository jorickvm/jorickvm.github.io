Importazione CSV

Aggiungi più soggiorni insieme da un foglio di calcolo salvato come CSV. AtlasDays convalida ogni riga, mostra un’anteprima e non salva nulla finché non confermi. È uno dei modi per aggiungere soggiorni passati.

Importa il file

  1. Apri Impostazioni → Importa → File CSV.
  2. Prepara il file in Sheets, Numbers o Excel ed esportalo come CSV. CSV di esempio mostra le intestazioni esatte con righe di esempio; il pulsante di condivisione salva il file come punto di partenza.
  3. Tocca Seleziona file CSV e scegli il file da File.
  4. Controlla l’anteprima, Trovato nel CSV.
  5. Tocca Importa e conferma.

Crea CSV con l’IA copia un prompt già pronto per ChatGPT, Claude o un altro assistente. Incolla le tue note di viaggio dopo il prompt e salva la risposta come CSV. Questi strumenti trattano il testo secondo le proprie informative sulla privacy: escludi le informazioni che non incolleresti altrove.

Puoi iniziare anche dal file stesso. Condividi un CSV da File, dai download di Safari o da Mail e scegli AtlasDays: si apre la stessa anteprima. AtlasDays viene proposto come opzione per i file CSV, senza diventare l’app predefinita.

Leggi l’anteprima

L’anteprima elenca le righe valide e mostra conteggi che puoi toccare per filtrare. Usa Seleziona tutto o Deseleziona tutto per scegliere cosa importare.

  • Duplicato: la riga è contenuta in un soggiorno già presente oppure ripete una riga precedente. Viene saltata.
  • Unisci: la riga comprende un soggiorno già presente nello stesso paese. All’importazione, quel soggiorno viene esteso per includere le date della riga, mentre note e motivi vengono combinati. Soggiorni da unire nel file indica righe del file che si uniscono tra loro.
  • Sovrapposizione: la riga si sovrappone in parte a un altro soggiorno. Potrebbe essere un secondo soggiorno reale o una seconda versione dello stesso: confronta le date prima di mantenerla.
  • Transiti e Stati USA contano le righe dei rispettivi tipi. Senza Pro, le righe degli stati vengono importate come normali soggiorni negli Stati Uniti.

Correggi gli errori nel file di origine

Le righe che AtlasDays non riesce a leggere compaiono sotto N righe con errori, con numero e motivo. Le righe non valide non vengono mai importate. Correggile nel foglio di calcolo, esporta di nuovo e seleziona nuovamente il file.

Nulla cambia finché non tocchi Importa. Selezionare un file e visualizzare l’anteprima non aggiunge soggiorni.

Reimporta un’esportazione

Un’esportazione in foglio di calcolo salvata come CSV può essere importata di nuovo, purché sia stata esportata in inglese: le intestazioni vengono lette solo in inglese. Per una copia completa di soggiorni, tracker e impostazioni, usa un backup.

Se tutte le righe non sono valide

Verifica che la prima riga contenga le intestazioni e includa Country, e che le date usino yyyy-mm-dd oppure un anno di quattro cifre. Il Riferimento del formato CSV elenca colonne supportate, valori e ogni messaggio di errore.

Continua con

  • Riferimento del formato CSV Tutte le colonne, i formati di data e gli errori supportati.
  • Importa soggiorni Scegli una fonte di importazione e controlla prima di salvare.
  • Backup e ripristino Conserva una copia di soggiorni, tracker e impostazioni.
