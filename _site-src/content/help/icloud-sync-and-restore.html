iCloud Sync and Restore

When iCloud Sync is enabled, AtlasDays stores trips and trackers in your private iCloud account and keeps them synchronized across devices using the same Apple Account.

Set up a new device

  1. Sign in to the same Apple Account and make sure iCloud Drive is available.
  2. Install AtlasDays and open Settings → iCloud Sync.
  3. Confirm iCloud Sync is on and review the displayed status.
  4. Leave AtlasDays open briefly while records arrive.

After reinstalling AtlasDays

Cloud-backed trips and trackers can return after the app reconnects to its iCloud store. Device-specific permissions, widget configuration, and some preferences may need to be set again.

Understand the status

The iCloud Sync screen reports whether AtlasDays is checking, syncing, waiting, synced, not signed in, or using local storage. Enabling or disabling sync can require closing AtlasDays from the app switcher and reopening it.

If data appears missing

  1. Do not reset or delete the app data while investigating.
  2. Confirm the Apple Account and iCloud availability.
  3. Check the iCloud Sync status and data count.
  4. Keep the app open on a stable connection and check again.
  5. Contact support before making destructive changes if another device still has the expected record.

Sync is not the same as an export

Sync keeps one evolving record across devices. An export is a separate file you control and can retain as a point-in-time copy.

If the screen says AtlasDays is not syncing

Follow the status message first. Check Apple Account sign-in, available iCloud storage, network access, and whether the app requests a restart after changing the toggle.
