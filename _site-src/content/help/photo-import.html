Photo Import

Photo Import scans location information in your photo library on the device, groups evidence into suggested trips, and lets you review everything before saving.

Start Photo Import

  1. Open Settings → Import → Photos.
  2. Allow Photos access if requested.
  3. Start the scan and keep AtlasDays open while it examines the selected library.
  4. Review the proposed trips before saving.

What AtlasDays examines

AtlasDays uses photo timestamps and embedded location coordinates when available. The scan and country resolution happen on your device; the photos themselves are not uploaded to AtlasDays.

Review every proposal

Check the country or US state, start and end dates, and any duplicate or overlap warning. A photo’s location is evidence, not proof of the exact moment you crossed a border.

Handle gaps conservatively

Photos without location information cannot support a suggestion. Long gaps between geotagged photos may also produce boundaries that need manual correction. Edit the saved trip in Timeline when better evidence is available.

If no trips are found

Confirm AtlasDays can access the intended photos, choose a period containing geotagged images, and check that location was enabled when those photos were taken.
