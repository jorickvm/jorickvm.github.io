AtlasDays / Help Center

Home Screen Widgets

Add AtlasDays from the iOS widget gallery, choose a Tracker or World Map layout, then configure the placed widget when needed.

Add a widget

  1. Long-press an empty area of the Home Screen until it enters editing mode.
  2. Tap + and search for AtlasDays.
  3. Choose Tracker or World Map, then swipe through the available sizes.
  4. Tap Add Widget and place it.

Choose a tracker

Long-press a placed Tracker widget, choose Edit Widget, and select the tracker. Each widget remembers its own selection, so several trackers can appear together.

Understand refresh timing

AtlasDays writes a new widget snapshot when relevant data changes, and iOS decides when the Home Screen redraws it. Open AtlasDays once after installing it or after a large edit so the widget has current data to draw.

Free and Pro layouts

The small Tracker widget and all World Map sizes are available with the free app. Medium and large Tracker layouts, including charts and forecasts, require AtlasDays Pro.

If a widget is blank or stale

Open AtlasDays once, confirm the selected tracker still exists, and wait for iOS to refresh the widget. For a differing count, compare the widget’s tracker selection with the tracker inside the app.
