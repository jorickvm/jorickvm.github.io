CSV Import

Bulk-add trips from a spreadsheet saved as CSV. AtlasDays validates every row, shows a preview, and saves nothing until you confirm. It is one of the ways to add past trips.

Import the file

  1. Open Settings → Import → CSV File.
  2. Prepare the file in Sheets, Numbers, or Excel and export it as CSV. Example CSV shows the exact headers with sample rows, and its share button saves the file as a starting point.
  3. Tap Select CSV File and choose the file from Files.
  4. Check the preview, Found in CSV.
  5. Tap Import and confirm.

Build CSV with AI copies a ready-made prompt for ChatGPT, Claude, or another assistant. Paste your travel notes after it and save the reply as a CSV. Those tools handle your text under their own privacy policies, so leave out anything you would not paste elsewhere.

You can also start from the file itself. Share a CSV file from Files, Safari's downloads, or Mail and choose AtlasDays: the same preview opens. AtlasDays is offered as an option for CSV files, never made their default app.

Read the preview

The preview lists valid rows and shows counts you can tap to filter. Use Select All or Deselect All to choose what to import.

  • Duplicate: the row sits inside a trip you already have, or repeats an earlier row. It is skipped.
  • Merge: the row covers a trip you already have in the same country. On import, that trip is widened to include the row's dates, and notes and purposes are combined. Merge candidates in file means rows within the file that join each other.
  • Overlap: the row partly overlaps another trip. It can be a genuine second stay or a second version of the same one, so compare dates before keeping it.
  • Transits and US states count rows of those kinds. Without Pro, state rows import as plain United States trips.

Fix errors in the source file

Rows AtlasDays cannot read appear under N rows with errors, with the row number and the reason. Invalid rows are never imported. Correct them in the spreadsheet, export again, and select the file again.

Nothing changes until Import. Selecting a file and viewing the preview does not add trips.

Re-importing an export

A Spreadsheet export saved as CSV can be imported again, provided it was exported in English: column headers are read in English only. For a full copy of trips, trackers, and settings, use a backup instead.

If every row is invalid

Check that the first row is a header row and contains Country, and that dates use yyyy-mm-dd or a four-digit year. The CSV Format Reference lists supported columns, values, and every error message.
