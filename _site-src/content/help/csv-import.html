CSV Import

Add trips from another travel app's export, a spreadsheet, or a day-by-day log saved as CSV. AtlasDays checks every row, shows a preview, and saves nothing until you confirm. It is one of the ways to add past trips.

Import the file

  1. Open Settings → Import → CSV File.
  2. Tap Select CSV File and choose the file from Files.
  3. Check the preview, Found in CSV.
  4. Tap Import and confirm.

Where the file can come from

  • From another app. Exports from other travel trackers usually work as they are. AtlasDays recognizes common names for the country and date columns, and reads files with one row per trip, one row per day, or one row per border crossing. The CSV Format Reference lists what it reads.
  • Use a CSV Template. To write the file yourself, open the template. Example CSV shows the headers with sample rows, and its share button saves the file as a starting point. Fill it in with Sheets, Numbers, or Excel and export it as CSV.
  • Build CSV with AI. When AtlasDays cannot read your file, or your travel history is in notes or screenshots, this opens a ready-made prompt. Copy it into ChatGPT, Claude, or another assistant, add your file, screenshots, or notes, and import the CSV it returns. AtlasDays only copies the prompt; it sends nothing. Those tools handle what you give them under their own privacy policies, so leave out anything you would not share elsewhere.

You can also start from the file itself. Share a CSV file from Files, Safari's downloads, or Mail and choose AtlasDays: the same preview opens. AtlasDays is offered as an option for CSV files, never made their default app.

Read the preview

The preview lists the rows it can import and shows counts you can tap to filter. Tap a row to correct it, or clear its selection to leave it out. With three or more rows, Select All and Deselect All change the whole list.

  • Duplicate: the row sits inside a trip you already have, or repeats an earlier row. It is skipped.
  • Merge: the row shares at least one day with a trip you already have in the same place. On import, that trip is widened to include the row's dates, and notes and purposes are combined. Merge candidates in file means rows within the file that join each other.
  • Overlap: the row shares a night with a trip in another country or US state. Compare the dates before keeping it.
  • Transits and US states count rows of those kinds. Without Pro, state rows import as plain United States trips.

Fix skipped rows in the source file

Rows AtlasDays cannot read are counted as N rows skipped and listed under Skipped, grouped by reason with their row numbers. Skipped rows are never imported. Correct them in the spreadsheet, export again, and select the file again.

Nothing changes until Import. Selecting a file and viewing the preview does not add trips.

Re-importing an export

A Spreadsheet export saved as CSV can be imported again, provided it was exported in English with dates as yyyy-mm-dd: column headers are read in English only. For a full copy of trips, trackers, your Profile, and settings, use a backup instead.

If no trips are found

When AtlasDays cannot use any row, the file stays on the setup screen and No Trips Found says why, for example that it could not find a country column. Tap Build CSV with AI there to have an assistant convert the file. The CSV Format Reference lists supported columns, values, and every error message.
