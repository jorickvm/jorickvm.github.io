CSV Format Reference

Only the Country column is required. AtlasDays finds columns by their English header name, so column order does not matter. Steps for importing are in CSV Import.

Columns

Recommended header row: Country,State,Start Date,End Date,Purpose,Notes. Header names are not case-sensitive. Unrecognized columns, such as Days, are ignored. If a header appears twice, the first one is used.

Country
Required. Country name in English or in the app language, ISO two-letter code, or a common alias such as USA, UK, or Holland. An alias that could mean two places is rejected.
State
Optional, United States trips only. State name, two-letter postal abbreviation, or ISO code such as US-CA. District of Columbia is accepted.
Start Date
Also accepted as Start. Date as yyyy-mm-dd, or a four-digit year.
End Date
Also accepted as End. Date as yyyy-mm-dd, or a four-digit year. Empty means ongoing (exact start) or the same year (year start).
Purpose
Personal, Business, Study, or Transit, not case-sensitive. Combine non-Transit values with commas inside quotes, such as "Business, Personal". Older Tourism and Medical import as Personal. A value that is not recognized is ignored without an error.
Notes
Also accepted as Note, Notes (optional). Free text.
Transit
Legacy column. Read only when there is no Purpose column. Yes, Y, True, or 1 marks Transit; No, N, False, 0, or empty does not.
Start Year, End Year
Legacy column. Four-digit years, used when the date cells hold no year. Cannot be combined with exact dates in the same row.

Date formats

Start DateEnd DateResult
2026-03-012026-03-05Exact trip. Same-day trips use the same date twice.
2026-03-01emptyOngoing trip with no end date.
2019emptyYear Only trip for that year.
20182019One Year Only trip covering 2018 to 2019.
emptyemptyTrip without dates.

Years must fall between 1900 and eight years after the current year. Exact dates and year values cannot be mixed within one row. Year Only trips and trips without dates count toward visited places and the map, but never toward day counts or trackers. A trip without dates can only be created through CSV import.

Special cases

  • US states. Use one row per state when one US visit covered several states. A plain United States row is valid for country-level tracking. A state name in the Country column (California, US-CA) also gives a US trip, and an empty Country with a valid State does the same. Two-letter codes that are also country codes, such as CA, stay countries. Without Pro, state rows import as plain United States trips.
  • Transit. Put Transit in Purpose when you did not enter the country. Transit is exclusive: if it appears with another purpose, only Transit is kept.
  • Delimiter and quoting. Comma, semicolon, and tab are detected from the header row. Quote fields that contain the delimiter or a line break.

Example

Country,State,Start Date,End Date,Purpose,Notes
France,,2026-03-01,2026-03-05,Personal,
United States,CA,2026-04-10,2026-04-15,Business,Conference
Japan,,2024,,Personal,Dates not known
United Arab Emirates,,2026-05-01,2026-05-01,Transit,Airport connection

Error messages

Each error appears in the preview with its row number, and the row is not imported. The row number counts the header as row 1.

Couldn't find a Country column
Put a header row first with a Country column.
Invalid country: '<value>'
Use an ISO code or an unambiguous country name.
Invalid state: '<value>'
Use a US state name, abbreviation, or US-XX code.
State '<value>' is only valid for United States trips
Clear State, or change Country to United States.
Conflicting states
The Country and State cells name different states. Keep one.
Invalid start date / Invalid end date
Use yyyy-mm-dd or a four-digit year.
Invalid start year / Invalid end year
Use a four-digit year in range.
Cannot have an end date without a start date
Add a Start Date.
Start date must be before or equal to end date
Swap or correct the dates.
End year must be after or equal to start year
Correct the years.
Cannot have an end year without a start year
Add a start year.
Cannot mix exact dates with approximate year fields
Use either dates or the legacy year columns.
Cannot mix exact start date with year-only end date, or year-only start with exact end date
Use two dates or two years in one row.
Invalid transit value
In the legacy Transit column use Yes/No, True/False, or 1/0.

If a value is not recognized

Use an ISO country code, ISO dates, and a standard US state name or code. A file exported from a spreadsheet in another language may carry translated headers, which are not recognized: rename them to the English headers above.
