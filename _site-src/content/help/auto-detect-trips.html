Auto-Detect Trips

Auto-Detect uses low-power background location monitoring to notice new travel and add a trip to Timeline immediately. You can review, edit, or undo it.

Turn on Auto-Detect

  1. Open Settings → Auto-Detect Trips.
  2. Turn on Auto-Detect Trips.
  3. Grant Always location access when iOS asks. The toggle remains off until background access is available.
  4. Optionally turn on notifications for new country detections.

Review detected trips

The new trip appears in Timeline with the detected country and the dates AtlasDays inferred. Open it to check the country or US state and the boundary dates, then edit or delete it if needed. If you receive a detection notification, choosing Ignore removes the trip; you can still add it by hand later.

Ignore places you do not want detected

Add countries to the Ignore list when recurring border proximity produces trips you never need. Pro users can also ignore individual US states. Ignored places can still be added manually.

Auto-Detect is not continuous GPS recording

The feature uses low-power system location events rather than storing a detailed route. Detection timing depends on iOS, geography, connectivity, and the available boundary signal.

If no trip appears

Check that Auto-Detect is on, Location is set to Always, the place is not ignored, and AtlasDays notifications are allowed if you expect a notification. You can always add the trip manually.
