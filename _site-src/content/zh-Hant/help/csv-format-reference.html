AtlasDays / 說明中心

CSV 格式參考

只有 Country 欄位是必填。AtlasDays 依英文標題名稱辨識欄位，所以欄位的先後順序不影響結果。匯入的步驟請見CSV 匯入。

欄位

建議的標題列：Country,State,Start Date,End Date,Purpose,Notes。標題名稱不分大小寫。無法辨識的欄位（例如 Days）會被忽略。若標題出現兩次，則採用第一個。

Country
必填。可填英文或 App 語言的國家名稱、ISO 兩碼代碼，或常見別名，例如 USA、UK 或 Holland。可能指兩個地方的別名會被拒絕。
State
選填，僅限美國行程。可填州名、兩碼郵政縮寫，或 US-CA 這類 ISO 代碼。也接受哥倫比亞特區（District of Columbia）。
Start Date
也可寫成 Start。日期格式為 yyyy-mm-dd，或四位數的年份。
End Date
也可寫成 End。日期格式為 yyyy-mm-dd，或四位數的年份。留空表示停留中（開始日期為精確日期），或同一年（開始日期為年份）。
Purpose
Personal（個人）、Business（商務）、Study（就學）或 Transit（轉機），不分大小寫。Transit 以外的多個值可放在引號內，以逗號分隔，例如 "Business, Personal"。舊有的 Tourism 與 Medical 會匯入為 Personal。無法辨識的值會被忽略，不會產生錯誤。
Notes
也可寫成 Note 或 Notes (optional)。自由文字。
Transit
舊版欄位。只有在沒有 Purpose 欄時才會讀取。Yes、Y、True 或 1 代表轉機；No、N、False、0 或留空則不是。
Start Year、End Year
舊版欄位。四位數的年份，用於日期欄位沒有年份的情況。同一列不能與精確日期並用。

日期格式

Start DateEnd Date結果
2026-03-012026-03-05精確日期的行程。同一天的行程，日期要寫兩次。
2026-03-01留空沒有結束日期、停留中的行程。
2019留空該年的僅年份行程。
20182019涵蓋 2018 至 2019 年的一筆僅年份行程。
留空留空沒有日期的行程。

年份必須介於 1900 與目前年份之後第 8 年之間。同一列不能混用精確日期與年份值。僅年份的行程與沒有日期的行程，會計入造訪過的地點與地圖，但不會計入天數或追蹤器。沒有日期的行程只能透過 CSV 匯入建立。

特殊情況

  • 美國各州。一次美國行程去了好幾個州時，每個州各寫一列。只寫 United States 的資料列有效，可用於國家層級的追蹤。在 Country 欄填州名（California、US-CA）同樣會得到美國行程，Country 留空但 State 有效時也一樣。同時也是國家代碼的兩碼代碼，例如 CA，仍視為國家。沒有 Pro 時，州別資料列會匯入為一般的美國行程。
  • 轉機。沒有實際入境時，在 Purpose 填入 Transit。Transit 具有排他性：若與其他目的並用，只會保留 Transit。
  • 分隔符號與引號。逗號、分號與 Tab 會從標題列自動判斷。內含分隔符號或換行的欄位，請加上引號。

範例

Country,State,Start Date,End Date,Purpose,Notes
France,,2026-03-01,2026-03-05,Personal,
United States,CA,2026-04-10,2026-04-15,Business,Conference
Japan,,2024,,Personal,Dates not known
United Arab Emirates,,2026-05-01,2026-05-01,Transit,Airport connection

錯誤訊息

每個錯誤都會在預覽中連同列號一起顯示，該列不會匯入。列號以標題列為第 1 列。

找不到 Country 欄位
請在最前面放一列標題列，並包含 Country 欄。
無效的國家：「<值>」
請使用 ISO 代碼或不會混淆的國家名稱。
無效的州別：「<值>」
請使用美國的州名、縮寫或 US-XX 代碼。
州別「<值>」只適用於美國行程
清除 State，或將 Country 改為 United States。
國家與州別不一致
Country 與 State 儲存格指向不同的州，請只保留一個。
無效的開始日期／無效的結束日期
請使用 yyyy-mm-dd 或四位數的年份。
無效的開始年份／無效的結束年份
請使用範圍內的四位數年份。
沒有開始日期就不能填寫結束日期
請補上 Start Date。
開始日期必須等於或早於結束日期
請對調或更正日期。
結束年份必須等於或晚於開始年份
請更正年份。
沒有開始年份就不能填寫結束年份
請補上開始年份。
精確日期和大約年份欄位不能混用
請只使用日期，或只使用舊版的年份欄位。
精確的開始日期不能搭配只有年份的結束日期（反之亦然）
同一列請使用兩個日期，或兩個年份。
Transit 欄的值無效
舊版 Transit 欄請使用 Yes/No、True/False 或 1/0。

某個值無法辨識時

請使用 ISO 國家代碼、ISO 日期，以及標準的美國州名或代碼。以其他語言的試算表匯出的檔案，標題可能被翻譯而無法辨識，請改回上述英文標題。
