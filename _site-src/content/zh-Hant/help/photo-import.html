照片匯入

照片匯入會在裝置上掃描照片圖庫中的日期與位置，整理成行程建議，經你確認之前不會儲存任何內容。這是新增過去行程的方式之一。若要把照片加入已有的行程，請使用尋找照片。

開始照片匯入

  1. 開啟設定 → 匯入 → 照片。畫面標題為在「照片」尋找過去的行程。
  2. 點一下在照片中尋找行程。
  3. iOS 詢問時，請選擇要讓 AtlasDays 取用哪些照片。允許完整取用可找到最多行程；若只允許選定的照片，AtlasDays 只會檢查你分享的照片。
  4. 掃描期間請讓 AtlasDays 保持開啟，然後點一下確認 N 個行程。

AtlasDays 會檢查什麼

AtlasDays 會讀取照片與影片的時間戳記與位置：有完整取用權限時讀取整個圖庫，否則只讀取你選定的照片。螢幕截圖與螢幕錄影會被略過。掃描與國家判定都在裝置上執行，離線也能使用，不會上傳任何內容給 AtlasDays。儲存的行程會保留照片的本機參照與小型快取預覽，原始檔案仍留在「照片」中。

只允許選定的照片時，掃描畫面會提供允許完整取用以找到更多行程。之後也可以在 iOS 的「設定」中更改取用權限。

逐一確認每個建議

確認畫面照片中找到的行程會列出建議的行程。摘要列會顯示重複、可合併、重疊、可能的轉機與美國州別的數量。每個行程可能帶有標籤，例如重複、合併、與現有行程重疊、中間日期為推估、國界附近或單張照片。匯入行程說明了重複、合併與重疊的意思。

  • 點一下行程即可更改國家或日期，取消勾選則可將它排除。行程有 3 個以上時，可用全選和取消全選一次變更整份清單。
  • 行程從該國第一張照片的日期開始，到最後一張照片的日期結束，所以日期只是推估。從訊息或網頁儲存的照片，可能會多出一個你從未造訪的國家。
  • 若最近的照片是近幾天拍的，最後一個行程會保留為停留中，因為你可能還在當地。
  • 有 Pro 時，美國各州會建議為個別的行程；沒有 Pro 時，則匯入為一般的美國行程。

點一下匯入並確認，即可將選取的行程儲存到時間軸。清單下方的關於這些建議說明了匯入前要檢查的事項。

照片是佐證，不是證明。兩趟相近行程之間的短暫停留，可能被標為轉機，而轉機不會計入天數總計。若某次停留確實在該國待過，請將該筆的轉機關閉。

保守處理紀錄空白

沒有位置資訊的照片無法作為行程建議的依據，含地理標記的照片之間若間隔過久，也可能推算出需要手動修正的行程邊界。取得更可靠的佐證後，可在時間軸編輯已儲存的行程。

將照片加入已有的行程

尋找照片會尋找在時間軸既有行程期間拍攝的照片和影片，不會建立行程。有行程之後，它就會出現在匯入行程中。

  1. 開啟設定 → 匯入 → 尋找照片。
  2. 點一下尋找符合行程的照片。AtlasDays 會檢查每個有精確日期且有地圖位置的行程，並略過國際空域與國際水域。
  3. 掃描結束後，點一下確認 N 個行程，在要加入的照片中檢查配對結果，再點一下加入照片。

若沒有找到新照片，會顯示找不到照片。尋找照片需要完整取用權限；若只允許選定的照片，需要照片取用權限提示會引導你前往「設定」。AtlasDays 儲存的是照片的參照，而不是副本，所以從圖庫刪除的照片也會從行程中消失。若要選擇在哪裡顯示照片預覽，請見外觀與個人化。

找不到任何行程時

若出現需要照片取用權限，請開啟 iOS 的「設定」，允許 AtlasDays 取用選定的照片或整個圖庫。若掃描結束後顯示照片中找不到行程，請確認拍照時有開啟定位；時間軸中已有的行程會標示為重複，不會再次建議。
