AtlasDays / ヘルプセンター

CSV形式リファレンス

必須の列はCountryだけです。AtlasDaysは列を英語のヘッダー名で見つけるため、列の並び順は自由です。インポートの手順はCSVインポートにあります。

列

推奨するヘッダー行はCountry,State,Start Date,End Date,Purpose,Notesです。ヘッダー名は大文字と小文字を区別しません。Daysのように認識されない列は無視されます。同じヘッダーが2つある場合は、最初のものが使われます。

Country
必須。英語またはアプリの言語での国名、ISOの2文字コード、またはUSA、UK、Hollandのように広く使われる別名。2つの場所を指しうる別名は受け付けられません。
State
任意。米国の旅行のみ。州名、郵便の2文字略号、またはUS-CAのようなISOコード。District of Columbiaも使えます。
Start Date
Startでも受け付けられます。yyyy-mm-dd形式の日付、または4桁の年。
End Date
Endでも受け付けられます。yyyy-mm-dd形式の日付、または4桁の年。空欄の場合、開始が正確な日付なら滞在中、開始が年なら同じ年になります。
Purpose
Personal、Business、Study、Transitのいずれかで、大文字と小文字は区別しません。Transit以外の値は、"Business, Personal"のように引用符の中でカンマで区切って組み合わせられます。旧形式のTourismとMedicalはPersonalとしてインポートされます。認識されない値は、エラーにならず無視されます。
Notes
Note、Notes (optional)でも受け付けられます。自由に書けるテキスト。
Transit
旧形式の列。Purpose列がない場合のみ読み取られます。Yes、Y、True、1は乗り継ぎとして扱われ、No、N、False、0、または空欄はそうなりません。
Start Year、End Year
旧形式の列。日付のセルに年が入っていない場合に使われる4桁の年。同じ行の正確な日付と併用できません。

日付の形式

Start DateEnd Date結果
2026-03-012026-03-05正確な日付の旅行。日帰りの旅行は同じ日付を2回書きます。
2026-03-01空欄終了日のない、滞在中の旅行。
2019空欄その年の「年のみ」の旅行。
201820192018年から2019年までをカバーする、1件の「年のみ」の旅行。
空欄空欄日付のない旅行。

年は、1900年から現在の年の8年後までの範囲でなければなりません。1つの行で、正確な日付と年の値を混在させることはできません。「年のみ」の旅行と日付のない旅行は、訪問済みの場所とマップには数えられますが、滞在日数やトラッカーには数えられません。日付のない旅行は、CSVインポートでしか作成できません。

特別なケース

  • 米国の州。1回の米国滞在で複数の州をまわった場合は、州ごとに1行ずつ書きます。国単位で記録するだけなら、通常のUnited Statesの行で問題ありません。Country列に州名（California、US-CA）を書いても米国の旅行になり、Countryが空で有効なStateがある場合も同様です。CAのように国コードとしても使われる2文字コードは、国として扱われます。Proでない場合、州の行は通常の米国の旅行としてインポートされます。
  • 乗り継ぎ。入国していない場合は、PurposeにTransitと書きます。Transitはほかの目的と併用できません。ほかの目的と一緒に書かれている場合は、Transitだけが残ります。
  • 区切り文字と引用符。カンマ、セミコロン、タブは、ヘッダー行から自動的に判別されます。区切り文字や改行を含むフィールドは、引用符で囲んでください。

例

Country,State,Start Date,End Date,Purpose,Notes
France,,2026-03-01,2026-03-05,Personal,
United States,CA,2026-04-10,2026-04-15,Business,Conference
Japan,,2024,,Personal,Dates not known
United Arab Emirates,,2026-05-01,2026-05-01,Transit,Airport connection

値が認識されないとき

ISOの国コード、ISO形式の日付、標準的な米国の州名またはコードを使ってください。ほかの言語のスプレッドシートから書き出したファイルには、翻訳されたヘッダーが含まれていることがあり、認識されません。上記の英語のヘッダーに書き換えてください。
