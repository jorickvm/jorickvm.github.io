AtlasDays / ヘルプセンター

CSV形式リファレンス

ファイルには、行ごとに国が必要です。滞在日数に数えたい旅行には、日付も必要です。AtlasDaysは列を英語のヘッダー名で見つけるため、列の並び順は自由です。ほかの旅行アプリが使う列名も認識します。インポートの手順はCSVインポートにあります。

列

自分で作るファイルに推奨するヘッダー行はCountry,State,Start Date,End Date,Purpose,Notesです。ヘッダー名は大文字と小文字を区別せず、アンダースコアはスペースとして扱われます。Daysのように認識されない列は無視されます。同じ意味の列が2つある場合は最初のものが使われますが、名前がちょうどPurposeの列は常に優先されます。

Country
Countries、Country Name、Country/Region、Nation、Place、Destinationからも読み取ります。英語またはアプリの言語での国名、ISOの2文字コード、またはUSA、UK、Hollandのように広く使われる別名。2つの場所を指しうる別名は受け付けられません。
Country Code
ISO、ISO Code、ISO2、Alpha-2、Code、CCからも読み取ります。2文字のコード。ファイルに国名とコードの両方がある場合は、コードが使われ、国名は無視されます。
State
US State、State/Province、Province、Region、Subdivisionからも読み取ります。米国の旅行のみ。州名、郵便の2文字略号、またはUS-CAのようなISOコード。District of Columbiaも使えます。
Start Date
Start、Arrival、Arrival Date、Entry、Date From、Begin、Check-inなどの名前からも読み取ります。下の「日付の形式」をご覧ください。
End Date
End、Departure、Departure Date、Exit、Date To、Until、Check-outなどの名前からも読み取ります。空欄の場合、開始が正確な日付なら滞在中、開始が年なら同じ年になります。
Purpose
Reason、Type、Trip Type、Category、Visit Typeからも読み取ります。Personal、Business、Study、Transitのいずれかで、大文字と小文字は区別しません。Transit以外の値は、"Business, Personal"のように引用符の中でカンマで区切るか、;または/で区切って組み合わせられます。よく使われる語は対応づけられます。WorkはBusiness、HolidayまたはVacationはPersonal、SchoolはStudy、LayoverはTransitになります。それ以外の値は、旅行のメモに「目的：」の行として残ります。
Notes
Note、Notes (optional)、Comment、Description、Remarks、Memoからも読み取ります。自由に書けるテキスト。
City
CitiesまたはTownからも読み取ります。旅行のメモに追加されます。
Is Current
CurrentまたはOngoingからも読み取ります。Yes、True、1の場合、終了日が何であっても旅行は滞在中のままになります。
Work Days、Personal Days
Purpose列がない場合に使われます。仕事の日だけの旅行はBusiness、個人の日だけの旅行はPersonalになります。両方がある旅行には「ビジネスと個人」というメモが付きます。
Transit
LayoverまたはAirsideからも読み取ります。Purpose列がない場合のみ読み取られます。Yes、Y、True、1は乗り継ぎとして扱われ、No、N、False、0、または空欄はそうなりません。
Start Year、End Year
旧形式の列。日付のセルに年が入っていない場合に使われる4桁の年。同じ行の正確な日付と併用できません。

ファイルのレイアウト

AtlasDaysは、列の構成から3つのレイアウトを見分けます。

  • 1行に1旅行：国と、開始日および終了日。テンプレート、AtlasDaysのスプレッドシートのエクスポート、そして多くの旅行アプリがこのレイアウトです。
  • 1行に1日：Date（またはDay）列と国。同じ国が続く日は1件の旅行にまとまり、1日でも抜けるとそこで旅行が終わります。最後の日が今日または昨日であれば、旅行は滞在中のまま残ります。1行目に日付と国が入っていれば、ヘッダー行は省略できます。1日に2か国にいた場合は、France|Germanyのように縦線で区切ると、両方の国にその日が数えられます。州や都市も同じように並べられます。
  • 1行に1回の国境通過：Date列と、FromおよびToの国。国境を越えた日は両方の国に数えられ、次に国境を越えるまでToの国に滞在していたものとして扱われます。最後の滞在は滞在中のまま残ります。国境通過の行は、1日ごとのファイルに混ぜることもできます。

Date列のないファイルでは、FromとToは旅行の開始日と終了日として読み取られます。

日付の形式

Start DateEnd Date結果
2026-03-012026-03-05正確な日付の旅行。日帰りの旅行は同じ日付を2回書きます。
2026-03-01空欄終了日のない、滞在中の旅行。
2019空欄その年の「年のみ」の旅行。
201820192018年から2019年までをカバーする、1件の「年のみ」の旅行。
空欄空欄日付のない旅行。

yyyy-mm-ddのほかに、次の形式も読み取ります。

  • 年が先頭で、スラッシュまたはドットで区切った形式（2026/03/01、2026.03.01など）。2026-03-01 22:47や2026-03-01T22:47:00Zのように日付のあとに時刻があっても、時刻は無視されます。
  • 英語の月名とその略称（1 Mar 2026、Mar 1, 2026、01-Mar-26など）。
  • 日が先頭、または月が先頭の形式（01/03/2026、03/01/2026など）。年は4桁でも2桁でもかまいません。01/03はどちらとも読めるため、ファイル内のいずれかの日付で日が12を超えていて順序が分かる場合にだけ読み取ります。そうでない場合、これらの行は「日と月を区別できません」としてスキップされます。

2桁の年は、20xxとみなして10年先までに収まる場合は20xx、そうでなければ19xxとして読み取ります。年は、1900年から現在の年の8年後までの範囲でなければなりません。1つの行で、正確な日付と年の値を混在させることはできません。「年のみ」の旅行と日付のない旅行は、訪問済みの場所とマップには数えられますが、滞在日数やトラッカーには数えられません。日付のない旅行は、CSVインポートでしか作成できません。

特別なケース

  • 米国の州。1回の米国滞在で複数の州をまわった場合は、州ごとに1行ずつ書きます。国単位で記録するだけなら、通常のUnited Statesの行で問題ありません。Country列に州名（California、US-CA）を書いても米国の旅行になり、Countryが空で有効なStateがある場合も同様です。CAのように国コードとしても使われる2文字コードは、国として扱われます。Proでない場合、州の行は通常の米国の旅行としてインポートされます。
  • 乗り継ぎ。入国していない場合は、PurposeにTransitと書きます。Transitはほかの目的と併用できません。ほかの目的と一緒に書かれている場合は、Transitだけが残ります。
  • 区切り文字と引用符。カンマ、セミコロン、タブは、ヘッダー行から自動的に判別されます。区切り文字や改行を含むフィールドは、引用符で囲んでください。

例

Country,State,Start Date,End Date,Purpose,Notes
France,,2026-03-01,2026-03-05,Personal,
United States,CA,2026-04-10,2026-04-15,Business,Conference
Japan,,2024,,Personal,Dates not known
United Arab Emirates,,2026-05-01,2026-05-01,Transit,Airport connection

同じフランス旅行を1行に1日の形式で書くと、次のようになります。

Date,Country
2026-03-01,France
2026-03-02,France
2026-03-03,France
2026-03-04,France
2026-03-05,France

値が認識されないとき

ISOの国コード、yyyy-mm-dd形式の日付、標準的な米国の州名またはコードを使ってください。ほかの言語のスプレッドシートから書き出したファイルには、翻訳されたヘッダーが含まれていることがあり、認識されません。上記の英語のヘッダーに書き換えてください。AtlasDaysがまったく読み取れないファイルは、インポート画面の「AIでCSVを作成」で変換用のプロンプトを使えます。
