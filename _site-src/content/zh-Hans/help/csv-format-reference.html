CSV 格式参考

只有 Country 列是必填的。AtlasDays 按英文表头名称识别列，所以列的先后顺序不影响结果。导入步骤见 CSV 导入。

列

推荐的标题行：Country,State,Start Date,End Date,Purpose,Notes。表头名称不区分大小写。无法识别的列（例如 Days）会被忽略。同一个表头出现两次时，采用第一个。

Country
必填。英文或 App 语言的国家名称、ISO 两位字母代码，或常见别名，例如 USA、UK、Holland。可能指向两个地方的别名会被拒绝。
State
选填，仅限美国的行程。州名、两位字母的邮政缩写，或 US-CA 这类 ISO 代码。哥伦比亚特区也可以。
Start Date
也可写作 Start。日期格式为 yyyy-mm-dd，或四位数的年份。
End Date
也可写作 End。日期格式为 yyyy-mm-dd，或四位数的年份。留空表示停留中（开始日期确切时），或与开始年份相同（开始为年份时）。
Purpose
Personal、Business、Study 或 Transit，不区分大小写。Transit 以外的多个值可以放在引号内，用逗号分隔，例如 "Business, Personal"。旧的 Tourism 和 Medical 会按 Personal 导入。无法识别的值会被忽略，不会报错。
Notes
也可写作 Note、Notes (optional)。自由文本。
Transit
旧版的列。只有在没有 Purpose 列时才会读取。Yes、Y、True 或 1 表示转机；No、N、False、0 或留空则不是。
Start Year、End Year
旧版的列。四位数的年份，在日期单元格里没有年份时使用。同一行里不能与确切日期并用。

日期格式

Start DateEnd Date结果
2026-03-012026-03-05确切日期的行程。当天往返的行程，两个日期填同一天。
2026-03-01留空停留中的行程，没有结束日期。
2019留空该年的仅年份行程。
20182019一条涵盖 2018 至 2019 年的仅年份行程。
留空留空没有日期的行程。

年份必须在 1900 年到当前年份之后八年之间。同一行里不能混用确切日期和年份值。仅年份的行程和没有日期的行程会计入到访过的地点和地图，但永远不计入天数或追踪器。没有日期的行程只能通过 CSV 导入创建。

特殊情况

  • 美国各州。一次赴美去了好几个州时，每个州各占一行。只填 United States 的数据行同样有效，可用于国家一级的记录。在 Country 列里填州名（California、US-CA）也会得到美国行程；Country 留空而 State 有效，效果相同。同时也是国家代码的两位字母代码，例如 CA，仍按国家处理。没有 Pro 时，州的数据行会作为普通的美国行程导入。
  • 转机。没有实际入境时，在 Purpose 填入 Transit。Transit 具有排他性：与其他目的同时出现时，只保留 Transit。
  • 分隔符与引号。逗号、分号和制表符会从标题行自动判断。字段内含分隔符或换行时，请加引号。

示例

Country,State,Start Date,End Date,Purpose,Notes
France,,2026-03-01,2026-03-05,Personal,
United States,CA,2026-04-10,2026-04-15,Business,Conference
Japan,,2024,,Personal,Dates not known
United Arab Emirates,,2026-05-01,2026-05-01,Transit,Airport connection

错误信息

每条错误都会连同行号显示在预览中，对应的数据行不会导入。行号把标题行算作第 1 行。

找不到 Country 列
先放一行标题行，并包含 Country 列。
国家无效：“<值>”
请使用 ISO 代码，或没有歧义的国家名称。
州无效：“<值>”
请使用美国的州名、缩写或 US-XX 代码。
“<值>”只适用于美国的行程
清空 State，或把 Country 改为 United States。
州数据不一致
Country 和 State 单元格指向不同的州，请只保留一个。
开始日期无效 / 结束日期无效
请使用 yyyy-mm-dd 或四位数的年份。
开始年份无效 / 结束年份无效
请使用范围内的四位数年份。
没有开始日期就不能填写结束日期
补上 Start Date。
开始日期必须等于或早于结束日期
对调或更正日期。
结束年份必须等于或晚于开始年份
更正年份。
没有开始年份就不能填写结束年份
补上开始年份。
精确日期和大约年份字段不能混用
只用日期，或只用旧版的年份列。
精确的开始日期不能搭配只有年份的结束日期，只有年份的开始日期也不能搭配精确的结束日期
同一行里请用两个日期，或两个年份。
Transit 列的值无效
在旧版的 Transit 列里，请使用 Yes/No、True/False 或 1/0。

如果某个值无法识别

请使用 ISO 国家代码、ISO 日期，以及标准的美国州名或代码。用其他语言的电子表格导出的文件，可能带有翻译过的表头，这些表头无法识别：请把它们改回上面的英文表头。
