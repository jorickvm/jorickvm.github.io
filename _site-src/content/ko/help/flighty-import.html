AtlasDays / 도움말 센터

Flighty 가져오기

Flighty에서 항공편 기록을 CSV로 내보내 AtlasDays에서 선택한 다음, 저장하기 전에 제안된 여행을 확인하십시오.

Flighty에서 내보내기

Flighty에서 항공편 기록을 CSV로 내보내고, iCloud Drive나 '나의 iPhone'처럼 iOS 파일 선택기가 접근할 수 있는 위치에 저장하십시오.

AtlasDays로 가져오기

  1. 설정 → 가져오기 → Flighty를 여십시오.
  2. Flighty CSV 선택을 탭하고 내보낸 파일을 고르십시오.
  3. AtlasDays가 확인 화면을 만들 때까지 기다리십시오.
  4. 제안된 체류, 환승 기록, 밤을 넘긴 경우, 중복, 겹침을 살펴보십시오.
  5. 타임라인에 남기고 싶은 행만 저장하십시오.

항공편이 여행이 되는 방식

도착 공항과 출발 공항은 체류의 근거가 되고, 연결 항공편은 환승으로 처리되기도 합니다. 밤을 넘기거나 간격이 촘촘한 항공편은 판단이 필요하므로, 확인 화면을 각 국가에 실제로 입국한 시점과 비교해 보십시오.

미국 주 확인

공항 정보로 미국 주를 알 수 있으면 AtlasDays가 주를 제안하기도 합니다. 주 단위로 관리하고 있다면 저장하기 전에 주를 확인하십시오.

파일이 거부되는 경우

Flighty CSV 내보내기를 새로 실행하고, 그렇게 만들어진 원본 파일을 선택하십시오. 스프레드시트에서 다시 저장했거나 순서를 바꾼 파일은 Flighty 형식과 맞지 않을 수 있습니다.
