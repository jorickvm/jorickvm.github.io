AtlasDays / 도움말 센터

언어 및 국가명

AtlasDays는 앱 인터페이스 언어와 국가명, 그리고 내보내거나 공유할 때 선택하는 언어를 각각 따로 설정합니다.

앱 언어 변경

  1. 설정 → 언어를 여십시오.
  2. 앱 언어를 탭하면 AtlasDays의 iOS 설정 화면이 열립니다.
  3. 그 화면에서 인터페이스 언어를 선택하십시오. iOS가 AtlasDays를 다시 실행하여 인터페이스 전체를 일관되게 다시 불러옵니다.

국가명 따로 선택

같은 화면에서 국가명을 선택하십시오. 국가명은 앱 언어를 따를 수도 있고, 지원되는 다른 언어를 사용할 수도 있습니다. 인터페이스는 한 언어로 보면서 국가명은 다른 언어로 보고 싶을 때 유용합니다.

내보내기와 공유 카드

스프레드시트, PDF, 공유 카드 화면에는 각자의 언어 선택 항목이 있을 수 있습니다. 이 출력 언어를 바꿔도 앱 인터페이스는 달라지지 않습니다.

일부 텍스트가 바뀌지 않은 경우

해당 화면을 닫았다가 다시 여십시오. 인터페이스 언어는 iOS 설정에서 바꾸며, AtlasDays는 iOS가 직접 다시 실행합니다.
