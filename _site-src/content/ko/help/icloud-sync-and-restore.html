AtlasDays / 도움말 센터

iCloud 동기화 및 복원

iCloud 동기화를 켜면 AtlasDays가 여행과 트래커를 개인 iCloud 계정에 저장하고, 같은 Apple 계정을 사용하는 기기 사이에서 동기화된 상태로 유지합니다.

새 기기 설정

  1. 같은 Apple 계정으로 로그인하고 iCloud Drive를 사용할 수 있는지 확인하십시오.
  2. AtlasDays를 설치한 다음 설정 → iCloud 동기화를 여십시오.
  3. iCloud 동기화가 켜져 있는지 확인하고 표시된 상태를 살펴보십시오.
  4. 기록이 도착하는 동안 AtlasDays를 잠시 열어 두십시오.

AtlasDays를 다시 설치한 후

iCloud에 보관된 여행과 트래커는 앱이 iCloud 저장소에 다시 연결되면 돌아오며, 첫 실행에서는 몇 분이 걸릴 수 있습니다. 기기별 권한, 위젯 구성, 일부 환경설정은 다시 지정해야 합니다.

상태 이해하기

iCloud 동기화 화면에는 AtlasDays가 확인 중인지, 동기화 중인지, 대기 중인지, 동기화됨 상태인지, 로그인 안 됨 상태인지, 로컬 저장 공간을 사용 중인지가 표시됩니다. 동기화를 켜거나 끌 때는 앱 전환기에서 AtlasDays를 완전히 종료했다가 다시 열어야 할 수 있습니다.

데이터가 보이지 않는 경우

  1. 원인을 확인하는 동안에는 앱 데이터를 재설정하거나 삭제하지 마십시오.
  2. Apple 계정과 iCloud 사용 가능 여부를 확인하십시오.
  3. iCloud 동기화 상태와 데이터 개수를 확인하십시오.
  4. 연결이 안정된 상태에서 앱을 열어 두고 다시 확인하십시오.
  5. 다른 기기에 해당 기록이 아직 남아 있다면, 되돌릴 수 없는 변경을 하기 전에 지원팀에 문의하십시오.

동기화와 내보내기는 다릅니다

동기화는 여러 기기에서 하나의 기록을 계속 최신 상태로 유지합니다. 내보내기는 직접 관리하는 별도의 파일이며, 특정 시점의 사본으로 보관할 수 있습니다.

화면에 동기화 안 됨으로 표시되는 경우

먼저 상태 메시지의 안내를 따르십시오. Apple 계정 로그인 상태, 사용 가능한 iCloud 저장 공간, 네트워크 연결, 그리고 스위치를 바꾼 뒤 앱이 재실행을 요청하는지 확인하십시오.
