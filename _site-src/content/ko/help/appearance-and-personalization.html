화면 모드 및 맞춤 설정

화면 모드 설정은 AtlasDays가 화면에서 보이고 동작하는 방식을 바꿉니다. 테마, 강조 색상, 배경 색조, 사진 미리보기, 애니메이션이 여기에 해당합니다. 여행, 집계된 일수, 트래커 규정은 바뀌지 않습니다.

테마 선택

설정 → 화면 모드를 여십시오. 테마에서 시스템을 고르면 iOS 설정을 따르고, 라이트 또는 다크를 고르면 고정됩니다.

화면 모드의 나머지 항목 조정

  • 미리보기 표시(사진 아래)는 여행에 사진 보관함의 사진 미리보기를 표시합니다. 끄면 숨겨집니다. AtlasDays는 작은 캐시 미리보기를 기기에 보관할 수 있으며, 원본은 사진 앱에 그대로 있습니다.
  • 애니메이션(요약 아래)은 요약과 트래커 카드에서 지도 표시 애니메이션과 숫자 증가 애니메이션을 재생합니다. 끄면 정적인 요약 화면이 됩니다.
  • UN 구분 표시(국가 아래)는 국가 선택 화면에서 유엔 회원국과 옵서버 국가를 표시합니다.

AtlasDays 맞춤 설정

설정 → 맞춤 설정을 여십시오. 화면 제목은 맞춤 설정이며, 선택한 내용은 저장 단계 없이 즉시 적용됩니다.

  • 강조 색상은 활성 컨트롤, 진행률 막대, 지도에서 방문한 장소의 색을 정합니다. 강조 색상은 무료입니다.
  • 배경 색조는 화면 배경에 색이 얼마나 입혀지는지를 정합니다. 끔, 약함, 보통, 강함 중에서 고를 수 있습니다.
  • 앱 아이콘은 AtlasDays Pro 사용자에게 여기에 나타나며, 다른 아이콘을 고를 수 있습니다.

위젯과 내보내기

AtlasDays는 라이트와 다크 화면 모드용 위젯 지도 이미지를 미리 준비하며, 어느 쪽이 표시될지는 홈 화면 환경에 따라 iOS가 결정합니다. 내보내기와 공유 카드에는 자체 옵션이 있습니다.

앱 아이콘이 바로 바뀌지 않는 경우

홈 화면으로 돌아가 iOS가 아이콘을 새로 고칠 때까지 잠시 기다리십시오. 이전 아이콘이 그대로라면 AtlasDays를 다시 실행하십시오.
