Import Flighty

Exportez votre historique de vols depuis Flighty au format CSV, sélectionnez le fichier dans AtlasDays, puis vérifiez les voyages proposés avant d’enregistrer.

Exporter depuis Flighty

Exportez votre historique de vols depuis Flighty au format CSV et enregistrez-le à un emplacement accessible depuis le sélecteur de fichiers d’iOS, comme iCloud Drive ou Sur mon iPhone.

Importer dans AtlasDays

  1. Ouvrez Réglages → Importer → Flighty.
  2. Touchez Sélectionner le CSV Flighty et choisissez le fichier exporté.
  3. Attendez qu’AtlasDays prépare la vérification de l’import.
  4. Vérifiez les séjours proposés, les enregistrements Transit, les cas de vols de nuit, les doublons et les chevauchements.
  5. N’enregistrez que les lignes que vous voulez voir dans la chronologie.

Comment les vols deviennent des voyages

Les aéroports d’arrivée et de départ fournissent des indices pour un séjour, tandis que les correspondances peuvent devenir des enregistrements Transit. Les vols de nuit et les vols très rapprochés peuvent demander un jugement, alors comparez la vérification de l’import avec votre entrée réelle dans chaque pays.

Vérifiez les États américains

Quand les informations d’aéroport le permettent, AtlasDays peut proposer un État américain. Confirmez l’État avant d’enregistrer si vous dépendez d’un suivi par État.

Si le fichier est refusé

Créez un nouvel export CSV depuis Flighty et sélectionnez ce fichier d’origine. Un fichier réenregistré ou réorganisé par un tableur peut ne plus correspondre au format de Flighty.
