Référence du format CSV

Seule la colonne Country (pays) est requise. AtlasDays repère les colonnes prises en charge par le nom de leur en-tête, leur ordre n’a donc pas d’importance.

En-têtes recommandés

Country,State,Start Date,End Date,Purpose,Notes

  • Country (pays) : nom de pays en anglais, code ISO à deux lettres ou alias courant reconnu.
  • State (État) : facultatif, nom d’un État américain, abréviation postale ou code de subdivision ISO comme US-CA.
  • Start Date / End Date (dates de début et de fin) : date exacte, année ou champ vide, selon les règles ci-dessous.
  • Purpose (motif) : Tourism (tourisme), Business (professionnel), Medical (médical), Transit ou Personal (personnel) ; plusieurs motifs hors Transit peuvent être séparés par des virgules.
  • Notes : texte libre, facultatif.

Formats de date

Dates exactes

Utilisez yyyy-mm-dd dans les deux colonnes de dates. Ne laissez End Date vide que pour un voyage en cours.

Année

Indiquez une année à quatre chiffres dans Start Date. End Date peut contenir une année, ou rester vide pour signifier la même année. Une plage couvrant plusieurs années devient, pour chaque année, un enregistrement Année uniquement.

Aucune date

Laissez les deux cellules de date vides. Le pays est conservé comme une visite sans dates : il compte pour les lieux visités mais jamais dans les totaux de jours, et les rapports l’étiquettent Date inconnue. Ce type d’enregistrement ne peut être créé que par l’import CSV.

Lignes avec un État américain

N’utilisez State que pour un voyage aux États-Unis. Si une même visite aux États-Unis a couvert plusieurs États et que vous avez besoin d’enregistrements par État, utilisez une ligne par État. Une simple ligne US reste valide pour un suivi au niveau du pays.

Transit

Inscrivez Transit dans Purpose pour un passage sans entrée dans le pays. Transit est exclusif : ne le combinez pas avec Tourism, Business ou un autre motif.

Exemple

Country,State,Start Date,End Date,Purpose,Notes
France,,2026-03-01,2026-03-05,Tourism,
United States,CA,2026-04-10,2026-04-15,Business,Conference
Japan,,2024,,Tourism,Dates not known
United Arab Emirates,,2026-05-01,2026-05-01,Transit,Airport connection

Séparateur et guillemets

AtlasDays reconnaît, à partir de la ligne d’en-têtes, les fichiers séparés par des virgules, des points-virgules ou des tabulations. Placez entre guillemets les champs qui contiennent le séparateur ou un saut de ligne, selon les règles CSV habituelles.

Si une valeur n’est pas reconnue

Utilisez un code de pays ISO, un nom de pays anglais sans ambiguïté, des dates ISO et un nom ou un code d’État américain standard. Conservez le numéro de ligne d’origine pour faciliter la comparaison avec la vérification de l’import.
