Référence du format CSV

Seule la colonne Country est requise. AtlasDays repère les colonnes par leur nom d’en-tête en anglais, l’ordre des colonnes n’a donc pas d’importance. Les étapes de l’import figurent dans Import CSV.

Colonnes

Ligne d’en-têtes recommandée : Country,State,Start Date,End Date,Purpose,Notes. Les noms d’en-têtes ne tiennent pas compte des majuscules. Les colonnes non reconnues, comme Days, sont ignorées. Si un en-tête apparaît deux fois, le premier est utilisé.

Country
Requis. Nom du pays en anglais ou dans la langue de l’app, code ISO à deux lettres, ou alias courant comme USA, UK ou Holland. Un alias pouvant désigner deux lieux est rejeté.
State
Facultatif, voyages aux États-Unis uniquement. Nom de l’État, abréviation postale à deux lettres ou code ISO comme US-CA. Le district de Columbia est accepté.
Start Date
Aussi accepté sous la forme Start. Date au format yyyy-mm-dd, ou année à quatre chiffres.
End Date
Aussi accepté sous la forme End. Date au format yyyy-mm-dd, ou année à quatre chiffres. Vide signifie en cours (début exact) ou la même année (début en année).
Purpose
Personal, Business, Study ou Transit, sans distinction de majuscules. Combinez les valeurs autres que Transit avec des virgules, entre guillemets, par exemple "Business, Personal". Les anciennes valeurs Tourism et Medical sont importées comme Personal. Une valeur non reconnue est ignorée sans erreur.
Notes
Aussi accepté sous les formes Note et Notes (optional). Texte libre.
Transit
Colonne héritée. Lue uniquement en l’absence de colonne Purpose. Yes, Y, True ou 1 marque un transit ; No, N, False, 0 ou une cellule vide n’en marque pas.
Start Year, End Year
Colonne héritée. Années à quatre chiffres, utilisées quand les cellules de date ne contiennent pas d’année. Ne peut pas être combinée avec des dates exactes sur la même ligne.

Les années doivent se situer entre 1900 et huit ans après l’année en cours. Les dates exactes et les années ne peuvent pas être mélangées sur une même ligne. Les voyages Année uniquement et les voyages sans dates comptent pour les lieux visités et la carte, mais jamais pour les décomptes de jours ni les suivis. Un voyage sans dates ne peut être créé que par l’import CSV.

Cas particuliers

  • États américains. Utilisez une ligne par État quand un même séjour aux États-Unis a couvert plusieurs États. Une simple ligne United States est valide pour un suivi au niveau du pays. Un nom d’État dans la colonne Country (California, US-CA) donne aussi un voyage aux États-Unis, tout comme une colonne Country vide avec un State valide. Les codes à deux lettres qui sont aussi des codes de pays, comme CA, restent des pays. Sans Pro, les lignes d’État sont importées comme de simples voyages aux États-Unis.
  • Transit. Inscrivez Transit dans Purpose quand vous n’êtes pas entré dans le pays. Transit est exclusif : s’il apparaît avec un autre motif, seul Transit est conservé.
  • Séparateur et guillemets. La virgule, le point-virgule et la tabulation sont détectés à partir de la ligne d’en-têtes. Placez entre guillemets les champs qui contiennent le séparateur ou un saut de ligne.

Exemple

Country,State,Start Date,End Date,Purpose,Notes
France,,2026-03-01,2026-03-05,Personal,
United States,CA,2026-04-10,2026-04-15,Business,Conference
Japan,,2024,,Personal,Dates not known
United Arab Emirates,,2026-05-01,2026-05-01,Transit,Airport connection

Messages d’erreur

Chaque erreur apparaît dans la vérification avec son numéro de ligne, et la ligne n’est pas importée. Le numéro de ligne compte l’en-tête comme la ligne 1. Les messages s’affichent dans la langue de l’app.

Colonne Country introuvable
Placez d’abord une ligne d’en-têtes avec une colonne Country.
Pays non valide : « <valeur> »
Utilisez un code ISO ou un nom de pays sans ambiguïté.
État non valide : « <valeur> »
Utilisez un nom d’État américain, une abréviation ou un code US-XX.
L’État « <valeur> » est valide uniquement pour les voyages aux États-Unis
Videz State, ou remplacez Country par United States.
États contradictoires
Les cellules Country et State désignent des États différents. N’en gardez qu’un.
Date de début non valide / Date de fin non valide
Utilisez yyyy-mm-dd ou une année à quatre chiffres.
Année de début non valide / Année de fin non valide
Utilisez une année à quatre chiffres dans la plage admise.
Une date de fin nécessite une date de début
Ajoutez une Start Date.
La date de début doit être antérieure ou égale à la date de fin
Inversez ou corrigez les dates.
L’année de fin doit être postérieure ou égale à l’année de début
Corrigez les années.
Une année de fin nécessite une année de début
Ajoutez une année de début.
Impossible de combiner des dates exactes et des champs d’année approximative
Utilisez soit des dates, soit les colonnes d’année héritées.
Impossible de combiner une date de début exacte et une année de fin seule, ou une année de début seule et une date de fin exacte
Utilisez deux dates ou deux années sur une même ligne.
Valeur de transit non valide
Dans la colonne Transit héritée, utilisez Yes/No, True/False ou 1/0.

Si une valeur n’est pas reconnue

Utilisez un code de pays ISO, des dates ISO et un nom ou un code d’État américain standard. Un fichier exporté depuis un tableur dans une autre langue peut contenir des en-têtes traduits, qui ne sont pas reconnus : renommez-les avec les en-têtes anglais ci-dessus.
