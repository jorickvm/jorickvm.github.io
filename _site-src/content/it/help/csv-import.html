Importazione CSV

Aggiungi soggiorni dall’esportazione di un’altra app di viaggio, da un foglio di calcolo o da un registro giorno per giorno salvato come CSV. AtlasDays controlla ogni riga, mostra un’anteprima e non salva nulla finché non confermi. È uno dei modi per aggiungere soggiorni passati.

Importa il file

  1. Apri Impostazioni → Importa → File CSV.
  2. Tocca Seleziona file CSV e scegli il file da File.
  3. Controlla l’anteprima, Trovato nel CSV.
  4. Tocca Importa e conferma.

Da dove può arrivare il file

  • Da un’altra app. Le esportazioni di altri tracker di viaggio di solito funzionano così come sono. AtlasDays riconosce i nomi più comuni delle colonne di paese e date e legge file con una riga per soggiorno, una riga per giorno o una riga per attraversamento di frontiera. Il Riferimento del formato CSV elenca cosa legge.
  • Usa un modello CSV. Per preparare il file in autonomia, apri il modello. CSV di esempio mostra le intestazioni con righe di esempio; il pulsante di condivisione salva il file come punto di partenza. Compilalo in Sheets, Numbers o Excel ed esportalo come CSV.
  • Crea CSV con l’IA. Quando AtlasDays non riesce a leggere il file, o lo storico dei viaggi è in note o schermate, questa opzione apre un prompt già pronto. Copialo in ChatGPT, Claude o un altro assistente, aggiungi il file, le schermate o le note e importa il CSV che ricevi. AtlasDays copia soltanto il prompt e non invia nulla. Questi strumenti trattano ciò che fornisci secondo le proprie informative sulla privacy: escludi le informazioni che non condivideresti altrove.

Puoi iniziare anche dal file stesso. Condividi un CSV da File, dai download di Safari o da Mail e scegli AtlasDays: si apre la stessa anteprima. AtlasDays viene proposto come opzione per i file CSV, senza diventare l’app predefinita.

Leggi l’anteprima

L’anteprima elenca le righe che può importare e mostra conteggi che puoi toccare per filtrare. Tocca una riga per correggerla oppure deselezionala per escluderla. Con tre o più righe, Seleziona tutto e Deseleziona tutto cambiano l’intero elenco.

  • Duplicato: la riga è contenuta in un soggiorno già presente oppure ripete una riga precedente. Viene saltata.
  • Unisci: la riga ha almeno un giorno in comune con un soggiorno già presente nello stesso luogo. All’importazione, quel soggiorno viene esteso per includere le date della riga, mentre note e motivi vengono combinati. Soggiorni da unire nel file indica righe del file che si uniscono tra loro.
  • Sovrapposizione: la riga ha una notte in comune con un soggiorno in un altro paese o stato USA. Confronta le date prima di mantenerla.
  • Transiti e Stati USA contano le righe dei rispettivi tipi. Senza Pro, le righe degli stati vengono importate come normali soggiorni negli Stati Uniti.

Correggi le righe ignorate nel file di origine

Le righe che AtlasDays non riesce a leggere vengono contate come N righe ignorate ed elencate sotto Ignorate, raggruppate per motivo con i numeri di riga. Le righe ignorate non vengono mai importate. Correggile nel foglio di calcolo, esporta di nuovo e seleziona nuovamente il file.

Nulla cambia finché non tocchi Importa. Selezionare un file e visualizzare l’anteprima non aggiunge soggiorni.

Reimporta un’esportazione

Un’esportazione in foglio di calcolo salvata come CSV può essere importata di nuovo, purché sia stata esportata in inglese con le date nel formato yyyy-mm-dd: le intestazioni vengono lette solo in inglese. Per una copia completa di soggiorni, tracker, Profilo e impostazioni, usa un backup.

Se non vengono trovati soggiorni

Quando AtlasDays non può usare nessuna riga, il file resta nella schermata di configurazione e Nessun soggiorno trovato spiega il motivo, per esempio che non ha trovato una colonna del paese. Tocca lì Crea CSV con l’IA per far convertire il file da un assistente. Il Riferimento del formato CSV elenca colonne supportate, valori e ogni messaggio di errore.
