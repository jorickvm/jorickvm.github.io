Esportazioni e report

Apri Impostazioni → Esporta, scegli Foglio di calcolo o Report PDF, imposta periodo e opzioni, visualizza l’anteprima e condividi il file. Per conservare una copia ripristinabile di tutto, usa Backup AtlasDays.

Scegli un’esportazione

  • Backup AtlasDays salva soggiorni, tracker e impostazioni in un file che si apre solo con AtlasDays. È gratuito. Vedi Backup e ripristino.
  • Foglio di calcolo crea una tabella Excel o CSV per analisi e registrazione dei dati.
  • Report PDF crea un report impaginato per pratiche, consulenti o il tuo archivio.

Le esportazioni vengono create sul dispositivo e non vengono mai caricate online. La voce Esporta nelle Impostazioni rimane indisponibile finché non hai almeno un soggiorno.

Imposta periodo e dettagli

Foglio di calcolo e PDF partono entrambi da un periodo: Da sempre, un Anno (solare o fiscale con una propria data iniziale) oppure un Intervallo di giorni recenti o date personalizzate. La riga sotto il periodo indica quanti soggiorni corrispondono e apre l’elenco alla base del numero.

La schermata Foglio di calcolo aggiunge colonne da includere, formato del file (Excel o CSV), lingua, formato delle date e ordine delle righe. La schermata PDF aggiunge impaginazione (per paese o cronologica), conteggio di giorni o notti, opzioni per motivo, note, stati USA, grafico dei paesi, riga per la firma, formato della carta e Seleziona per l’esportazione, dove puoi escludere singole voci. Decidi cosa deve contenere il file prima di condividerlo: un’esportazione può contenere più dettagli di quanti servano al destinatario.

Aggiungi dati personali a un PDF

Il report PDF può includere nome, nazionalità, passaporto, data di nascita e campi personalizzati. Scegli Dati personali, compila ciò che desideri e attiva Mostra nel report. Questi dati sono conservati solo su questo dispositivo e non fanno parte di un backup AtlasDays.

Controlla l’anteprima, poi condividi

Tocca Esporta foglio di calcolo o Esporta PDF per aprire l’anteprima, poi usa il pulsante di condivisione per inviare il file. Se manca un soggiorno o è errato, torna alla Cronologia, correggilo ed esporta di nuovo. Creare o condividere un’esportazione non modifica mai i soggiorni; il file è una copia separata.

Le esportazioni in foglio di calcolo e PDF richiedono AtlasDays Pro. Senza Pro puoi esplorarle e configurarle, ma il pulsante mostra Passa a Pro. Mantieni privati i file esportati: contengono uno storico di viaggio dettagliato e non sono più protetti da AtlasDays dopo la condivisione.

Se nel file manca un soggiorno

Controlla prima il periodo dell’esportazione. Per un PDF, apri anche Seleziona per l’esportazione: le voci senza date esatte, come i soggiorni Solo anno, sono elencate sotto Date approssimative e non possono apparire nel report.
