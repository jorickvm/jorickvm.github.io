Esportazioni e report

Apri Impostazioni → Esporta, scegli Foglio di calcolo o Report PDF, imposta periodo e opzioni, visualizza l’anteprima e condividi il file. I report PDF vengono conservati anche nel tuo Profilo. Per conservare una copia ripristinabile di tutto, usa Backup AtlasDays.

Scegli un’esportazione

  • Backup AtlasDays salva soggiorni, tracker, il tuo Profilo e le impostazioni in un file che si apre solo con AtlasDays. È gratuito. Vedi Backup e ripristino.
  • Foglio di calcolo crea una tabella Excel o CSV per analisi e registrazione dei dati.
  • Report PDF crea un report impaginato per pratiche, consulenti o il tuo archivio.

Le esportazioni vengono create sul dispositivo e non vengono mai caricate online. La voce Esporta nelle Impostazioni rimane indisponibile finché non hai almeno un soggiorno.

Imposta periodo e dettagli

La prima volta che apri Foglio di calcolo o Report PDF su un dispositivo, una breve introduzione ne spiega il funzionamento; tocca Continua. Poi entrambi partono da un periodo: Da sempre, un Anno (solare o fiscale con una propria data iniziale) oppure un Intervallo di giorni recenti o date personalizzate. La riga sotto il periodo indica quanti soggiorni corrispondono e apre l’elenco alla base del numero. Tocca un soggiorno in quell’elenco per correggerlo prima di esportare, oppure tienilo premuto e scegli Apri per aprirne la pagina.

La schermata Foglio di calcolo aggiunge colonne da includere, formato del file (Excel o CSV), lingua, formato delle date e ordine delle righe. La schermata PDF aggiunge impaginazione (per paese o cronologica), conteggio di giorni o notti, opzioni per motivo, note, stati USA, grafico dei paesi, riga per la firma, formato della carta e Seleziona per l’esportazione, dove puoi escludere singole voci. Decidi cosa deve contenere il file prima di condividerlo: un’esportazione può contenere più dettagli di quanti servano al destinatario.

Aggiungi dati personali a un PDF

Il report PDF può includere nome, nazionalità, passaporto, data di nascita e campi personalizzati. Scegli Dati personali, compila ciò che desideri e attiva Mostra nel report. Questi dati sono conservati solo su questo dispositivo e non fanno parte di un backup AtlasDays.

Controlla l’anteprima, poi condividi

Tocca Esporta foglio di calcolo o Crea report per aprire l’anteprima, poi usa il pulsante di condivisione per inviare il file. Se un soggiorno è errato, correggilo dall’elenco dei soggiorni corrispondenti o nella Cronologia. Se ne manca uno, aggiungilo nella Cronologia. Poi esporta di nuovo. Creare o condividere un’esportazione non modifica mai i soggiorni; il file è una copia separata.

Report salvati nel Profilo

Ogni PDF creato con Crea report viene salvato in Report nel tuo Profilo, come conferma Salvato in Profilo. Aprilo lì in seguito per rivederlo o condividerlo di nuovo, oppure tocca Crea report nel Profilo per crearne uno nuovo. I report salvati restano su questo dispositivo: non vengono sincronizzati e non fanno parte di un backup. Per rimuoverne uno, tienilo premuto e scegli Elimina report.

Le esportazioni in foglio di calcolo e PDF richiedono AtlasDays Pro. Senza Pro si aprono sulla loro introduzione, con il pulsante Passa a Pro. Mantieni privati i file esportati: contengono uno storico di viaggio dettagliato e non sono più protetti da AtlasDays dopo la condivisione.

Se nel file manca un soggiorno

Controlla prima il periodo dell’esportazione. Per un PDF, apri anche Seleziona per l’esportazione: le voci senza date esatte, come i soggiorni Solo anno, sono elencate sotto Date approssimative e non possono apparire nel report.
