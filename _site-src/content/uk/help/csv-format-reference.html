AtlasDays / Довідка

Довідник із формату CSV

Обов’язковий лише стовпець Country (Країна). AtlasDays знаходить підтримувані стовпці за назвою заголовка, тому їхній порядок не має значення.

Рекомендовані заголовки

Country,State,Start Date,End Date,Purpose,Notes

  • Country (Країна): назва країни англійською, дволітерний код ISO або поширена альтернативна назва, яку програма розпізнає.
  • State (Штат): необов’язкове поле — назва штату США, поштове скорочення або код регіону за ISO, наприклад US-CA.
  • Start Date / End Date (Дата початку та дата завершення): точна дата, рік або порожня клітинка за правилами нижче.
  • Purpose (Мета): Tourism (Туризм), Business (Робота), Medical (Лікування), Transit (Транзит) або Personal (Особисте); кілька цілей, окрім Transit, можна перелічити через кому.
  • Notes (Примітки): необов’язковий текст.

Формати дат

Точні дати

В обох стовпцях дат використовуйте yyyy-mm-dd. Залишайте End Date порожнім лише для поїздки, яка триває.

Рік

У Start Date вкажіть чотиризначний рік. End Date може містити рік або залишатися порожнім, і тоді це той самий рік. Діапазон, що охоплює кілька років, перетворюється на окремий запис «Тільки рік» для кожного року.

Зовсім без дат

Залиште обидві клітинки дат порожніми. Країна збережеться як відвідування без дат: воно зараховується до відвіданих місць, але ніколи не входить у підрахунок днів, а у звітах позначається як «Невідома дата». Такий запис можна створити лише через імпорт CSV.

Рядки для штатів США

Стовпець State використовуйте лише для поїздок до США. Якщо одна поїздка Сполученими Штатами охопила кілька штатів і вам потрібні записи по кожному з них, створіть окремий рядок для кожного штату. Для обліку на рівні країни достатньо звичайного рядка з США.

Транзит

Укажіть у стовпці Purpose значення Transit (Транзит), якщо ви не в’їжджали до країни. Transit виключає інші цілі: не поєднуйте його з Tourism, Business або будь-якою іншою метою.

Роздільники та лапки

AtlasDays визначає за рядком заголовків, чим розділені поля: комою, крапкою з комою чи табуляцією. Поля, усередині яких є роздільник або перенесення рядка, беріть у лапки за звичайними правилами CSV.

Якщо значення не розпізнано

Використовуйте код країни за ISO, однозначну англійську назву країни, дати у форматі ISO та стандартну назву або код штату США. Зберігайте вихідні номери рядків, щоб їх було легко звірити з попереднім переглядом імпорту.
