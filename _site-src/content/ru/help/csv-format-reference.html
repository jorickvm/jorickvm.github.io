AtlasDays / Справка

Справочник по формату CSV

Обязателен только столбец Country (Страна). AtlasDays находит поддерживаемые столбцы по имени заголовка, поэтому их порядок не важен.

Рекомендуемые заголовки

Country,State,Start Date,End Date,Purpose,Notes

  • Country (Страна): название страны на английском, двухбуквенный код ISO или распространённое альтернативное название, которое приложение распознаёт.
  • State (Штат): необязательное поле — название штата США, почтовое сокращение или код региона по ISO, например US-CA.
  • Start Date / End Date (Дата начала и дата окончания): точная дата, год или пустая ячейка по правилам ниже.
  • Purpose (Цель): Tourism (Туризм), Business (Работа), Medical (Лечение), Transit (Транзит) или Personal (Личное); несколько целей, кроме Transit, можно перечислить через запятую.
  • Notes (Заметки): необязательный текст.

Форматы дат

Точные даты

В обоих столбцах дат используйте yyyy-mm-dd. Оставляйте End Date пустым только для текущей поездки.

Год

В Start Date укажите четырёхзначный год. В End Date можно указать год или оставить ячейку пустой, и тогда это тот же год. Диапазон, охватывающий несколько лет, превращается в отдельную запись «Только год» для каждого года.

Совсем без дат

Оставьте обе ячейки дат пустыми. Страна сохранится как посещение без дат: оно засчитывается в число посещённых мест, но никогда не входит в подсчёт дней, а в отчётах помечается как «Неизвестная дата». Такую запись можно создать только через импорт CSV.

Строки для штатов США

Столбец State используйте только для поездок в США. Если одна поездка по США охватила несколько штатов и вам нужны записи по каждому из них, создайте отдельную строку для каждого штата. Для учёта на уровне страны достаточно обычной строки с США.

Транзит

Укажите в столбце Purpose значение Transit (Транзит), если вы не въезжали в страну. Transit исключает остальные цели: не сочетайте его с Tourism, Business или другой целью.

Пример

Country,State,Start Date,End Date,Purpose,Notes
France,,2026-03-01,2026-03-05,Tourism,
United States,CA,2026-04-10,2026-04-15,Business,Conference
Japan,,2024,,Tourism,Dates not known
United Arab Emirates,,2026-05-01,2026-05-01,Transit,Airport connection

Разделители и кавычки

AtlasDays определяет по строке заголовков, чем разделены поля: запятой, точкой с запятой или табуляцией. Поля, внутри которых есть разделитель или перенос строки, заключайте в кавычки по обычным правилам CSV.

Если значение не распознано

Используйте код страны по ISO, однозначное английское название страны, даты в формате ISO и стандартное название или код штата США. Сохраняйте исходные номера строк, чтобы их было легко сверить с предпросмотром импорта.
