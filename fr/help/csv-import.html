Import CSV

Préparez un CSV avec une ligne d’en-têtes, choisissez-le dans Réglages → Importer → CSV, puis traitez la vérification de l’import avant d’enregistrer le moindre voyage.

Importer le fichier

  1. Ouvrez Réglages → Importer → CSV.
  2. Appuyez-vous sur l’exemple ou sur la référence du format pour préparer le fichier.
  3. Sélectionnez le CSV dans Fichiers.
  4. Vérifiez les lignes valides, les lignes non valides, les doublons et les avertissements de chevauchement.
  5. Importez les lignes que vous acceptez.

Corrigez les erreurs dans le fichier source

La vérification de l’import indique le numéro de ligne et la raison quand elle ne peut pas reconnaître un pays, un État, une date ou un en-tête requis. Corrigez cette ligne dans le CSV, puis importez de nouveau le fichier.

Les avertissements sont des invitations à vérifier

Un doublon peut répéter un voyage déjà présent dans la chronologie. Un chevauchement peut être légitime ou représenter deux versions du même séjour. Contrôlez les dates et les lieux au lieu d’accepter toutes les lignes automatiquement.

Seul l’enregistrement modifie votre chronologie

Sélectionner un fichier et consulter la vérification de l’import n’ajoute aucun voyage. AtlasDays n’écrit les lignes acceptées qu’après l’action d’import finale.

Si toutes les lignes sont non valides

Confirmez que la première ligne contient un en-tête Country et vérifiez le format exact des dates. Consultez la référence du format CSV pour les colonnes prises en charge et des exemples.
